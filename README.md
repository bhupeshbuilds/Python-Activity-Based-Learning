## Assignment Overview
This repository contains solutions, documentation, and assets for 10 difficult-level case studies selected from the prescribed list of 100 problems for the Python Programming Activity-Based Learning coursework.

Each case study module includes:
- Problem Statement & Objectives
- Assumptions & Constraints
- Algorithm & Flowchart
- Pseudocode
- Executable Python Source Code
- Test Cases (Valid, Invalid, Boundary)
- Terminal Output Screenshots
- Conclusion & Complexity Analysis
